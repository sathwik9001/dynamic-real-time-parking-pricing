 Dynamic Real-Time Parking Pricing Engine
A real-time, demand-aware pricing system for urban parking lots. Built using Python, Pandas, NumPy, and Bokeh, this project simulates price adjustments based on occupancy, queue length, traffic, vehicle type, special events, and competitor prices. Includes three custom models, live streaming simulation, and interactive visualizations to optimize parking lot efficiency and revenue.
